Projeto — Reprodução de Telas de Login
📌 Sobre o projeto


Este projeto tem como objetivo reproduzir, utilizando HTML, CSS e JavaScript, um conjunto de 5 telas de login desenvolvidas no Figma.

O desafio consiste em analisar o protótipo, compreender sua estrutura visual e funcional e desenvolver uma versão web que seja o mais fiel possível ao projeto apresentado.

🎨 Protótipo no Figma


### O projeto original pode ser acessado pelo link do [figma](https://www.figma.com/design/nHMnLlAbtj5xATmhCrOyOY/Tela-Login?node-id=4-193&t=mcPRK7e96um34KbV-1)

Importante: utilize o protótipo do Figma como referência visual para a construção das telas.


🚀 Objetivos

Ao desenvolver este projeto, você deverá praticar:

Estruturação de páginas utilizando HTML;\
Estilização e reprodução de layouts utilizando CSS;\
Organização de elementos utilizando recursos como Flexbox e/ou CSS Grid;\
Utilização de imagens, ícones e outros assets;\
Manipulação de elementos HTML com JavaScript;\
Captura de dados inseridos em formulários;\
Validação de campos;\
Utilização do Console do navegador para visualizar informações;\
Organização de arquivos e código em um projeto web.

O projeto deverá reproduzir as 5 telas de login apresentadas no protótipo do Figma.

A implementação deverá buscar a maior fidelidade possível em relação ao projeto original, considerando:

Cores;

Tamanhos;
Espaçamentos;
Bordas;
Ícones;

Após criar a sua fork:

Clone o seu repositório para o computador;
Desenvolva o projeto localmente;

Envie as alterações para a sua fork.


🖥️ Telas

O projeto é composto por 5 telas de login.

Todas as telas deverão ser reproduzidas de acordo com o protótipo disponibilizado no Figma.

A implementação deve considerar não apenas a aparência visual, mas também os elementos de formulário presentes nas telas.


📝 Validação dos campos

Os formulários deverão possuir validações para os campos de:

E-mail
Senha

O campo de e-mail deverá verificar se o valor informado possui um formato válido de e-mail.

Exemplos de situações que devem ser consideradas:

Campo vazio;\
E-mail sem @;\
E-mail sem domínio;\
Formato de e-mail inválido.\
Senha

O campo de senha deverá possuir uma validação mínima (Mínimo de 8 caracteres, letras maiúsculas e minúsculas, números, caracteres especiais).

O sistema deverá identificar quando o campo estiver vazio ou quando o valor não atender aos critérios estabelecidos.

As mensagens de validação devem ser apresentadas de maneira clara para o usuário.


🧑‍💻 Captura dos dados

Ao realizar o envio do formulário, os dados digitados pelo usuário deverão ser capturados utilizando JavaScript.

Nesta primeira etapa do projeto, não é necessário implementar um backend ou realizar autenticação real.

Os dados deverão ser exibidos no Console do navegador para fins de teste e aprendizado.

Por exemplo, ao enviar o formulário, deverá ser possível visualizar no console informações referentes ao:

E-mail informado;
Senha informada.

⚠️ Atenção: a exibição da senha no console é uma exigência exclusivamente para fins didáticos deste exercício. Em aplicações reais, senhas não devem ser expostas dessa maneira.


🎞️ Animações

Nesta primeira etapa do projeto, não será necessário implementar animações ou transições.

O foco principal será:

Reproduzir visualmente as telas;
Estruturar corretamente o HTML;
Desenvolver o CSS;
Implementar as validações;
Capturar os dados dos formulários;
Exibir os dados no console do navegador.

Animações e outros comportamentos visuais poderão ser abordados em etapas futuras.
